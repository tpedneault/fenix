Vim's grammar. A leader key for everything else.

Fenix is a keyboard-first editor written from scratch in Rust. Real Vim editing, Git, a debugger, coding agents and terminals live in one GPU-rendered window, each a few keys away.

Everything a working day needs, a few keys away.

Fenix brings the tools you'd otherwise switch windows for into pages you move between with the keyboard, and none of them asks for a plugin hunt first.

hjkl · ciw · @q

Vim, for real

Motions, operators, text objects, counts, registers, macros, marks and Visual modes. Not an emulation layered on top: the editor is built around them.

SPC g

Git as a daily driver

Stage hunks, commit, blame, browse the graph, compare side by side, rebase interactively and resolve conflicts, then undo a Git operation you regret.

SPC u

A debugger in the code

Breakpoints and the current line in the gutter, values written inline, the F-keys you know, and a dock for the stack, variables and console.

SPC l

Language servers, merged

Completion, hover, diagnostics and a rename you preview across files. Several servers on one file, their answers merged into one.

SPC e · SPC /

Projects and files

A project hub, fuzzy pickers, a search page that replaces across the project, a file explorer, and terminals that start where you work.

:w

Built not to lose work

Staged, atomic saves, recovery for unsaved buffers after a crash, and your windows, splits and cursors back as you left them.

SPC a · CODING AGENTS

Agents work beside your code. You keep the last word.

Claude Code, Codex, Devin, Gemini CLI, or any agent that speaks the Agent Client Protocol, runs in a dock beside the file you're in. You see each command as it runs, and every change it makes is a hunk you accept or reject.

Run fenix --mcp and agents can ask Fenix back: its language servers, diagnostics and open buffers.

SPC h x · THE STORE

Extensions in a sandbox, from a signed store.

Each extension is a WebAssembly component that may do only what its manifest asks for, and you see that list before you install. The registry is signed, and every package is checked against it.

The installer needs no administrator. It adds Fenix to the Start menu and your PATH, and a newer one upgrades in place.
